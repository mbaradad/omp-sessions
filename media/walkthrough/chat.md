# Talk to the agent

- `/` completes omp's commands and the extension's (`/tree`, `/fork`, `/goal`, `/btw`, `/agents`, `/changes`, `/queue` …)
- `@` completes files, `!cmd` runs a shell command in the session
- Paste or drop **images** (sent to the model) and **any file** — PDFs, docs — (staged next to the session for omp to read)
- ↑/↓ recall prompts; hover your messages to **edit & resend** or **fork**
- Every path and URL in the chat is clickable
