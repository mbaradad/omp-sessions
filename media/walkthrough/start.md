# Start a background session

Click **+** in the omp **Sessions** view (or run *omp: New Session*). The session runs on the machine your workspace lives on — over Remote-SSH that's the server, locally it's your computer — and keeps running when VS Code closes, the laptop sleeps or SSH drops. Reopen VS Code and the chat reattaches with everything that happened meanwhile.

*New Session with Options…* picks model, thinking level, approvals, plan-first, a goal and any omp flag.
