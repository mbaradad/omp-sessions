# From the editor

- Lightbulb on a problem → **Fix with omp**; on a selection → **Explain with omp** / **Ask omp about this…**
- **Add to Switchyard Chat** on files and folders (Explorer, editor tab)
- **Send Terminal Selection to omp** from the terminal menu
- Source Control `…` → **Commit with omp**, **Review Uncommitted Changes**, **Write PR Description**
- `Cmd+Alt+O` focuses the chat, `Cmd+Alt+K` sends the selection
