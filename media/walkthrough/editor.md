# From the editor

- Lightbulb on a problem → **Fix with Agent**; on a selection → **Explain with Agent** / **Ask Agent about this…**
- **Add to Switchyard Chat** on files and folders (Explorer, editor tab)
- **Send Terminal Selection to Session** from the terminal menu
- Source Control `…` → **Commit with Agent**, **Review Uncommitted Changes**, **Write PR Description**
- `Cmd+Alt+O` focuses the chat, `Cmd+Alt+K` sends the selection
