Switchyard planner

One per user. Holds your plans: task graphs, queues, schedules, the concurrency limit and usage holds. Starts each task when it is ready, also after a reboot.

Agent Orchestrator

The AO daemon gives each session a git worktree and a chat host that outlives every client; holds approvals.

omp

oh-my-pi in the session's worktree: your models, tools, skills. Switchyard's extension adds modes and undo.

keeps working

Repository

A branch ao/<session>/root per session: diff it, revert, undo a turn, merge.
