Your sessions, in your pocket.

The omp-vs server serves a small web app. Scan a QR code from VS Code and add it to your home screen.

  • See what's working, waiting or done
  • Follow a session live and prompt or steer it
  • Approve or deny tool calls; switch the permission mode
  • Start a session in a recent folder, or queue it
Over Tailscale (free, encrypted) or your Wi-Fi. Token-protected; the same JSON + SSE API is open to your own apps.
